# RedNote CTR C 端使用手册

## 这个工具做什么

RedNote CTR 用来帮助你在多张小红书封面里，先筛出更可能被点击的版本，并发布一个内测页面收集真实点击数据。

## 使用流程

### 1. 打开网站

访问管理员发你的测试链接，进入 RedNote CTR 工作台。

### 2. 上传候选封面

在左侧“候选封面”区域点击“选择封面图片”，一次可以上传多张。

建议：

- 每次上传 5-20 张。
- 封面比例尽量使用小红书常见竖版比例。
- 同一篇笔记的候选封面放在同一批里测试。

### 3. 查看预测结果

上传后，系统会为每张封面显示：

- 预估 CTR
- 视觉亮度
- 色彩刺激
- 主体反差
- 模型置信度
- 相似历史样本

右侧会显示推荐前三张封面。

### 4. 生成轻改封面

如果某张封面基础不错，可以点击：

```text
一键轻改
```

系统会生成一个本地轻改版本，用来模拟后续 AI 图片模型改图能力。

当前轻改主要优化：

- 亮度
- 对比度
- 色彩刺激
- 标题区域识别度
- 信息流缩略图可读性

### 5. 发布封面内测

在候选封面卡片里点击：

```text
加入内测
```

至少选择 2 张后，点击左侧：

```text
发布封面内测
```

系统会生成一个小红书样式的双列信息流页面。

### 6. 分享内测链接

在“内测结果”里点击：

```text
复制链接
```

把链接发给测试用户。用户打开后，只需要点击自己最想打开的一张封面。

### 7. 查看内测结果

回到“内测结果”，可以看到每张封面的：

- 曝光数
- 点击数
- 实测 CTR
- 排名

CTR 最高的封面，优先作为发布或投放版本。

## 数据维护说明

运营样本主表在：

```text
data/rednote_ctr_sample_library.xlsx
```

封面图片放在：

```text
data/images/
```

Excel 的 `filename` 必须和图片文件名一致。

## 当前 MVP 限制

- 当前预测是 MVP 级别，不代表真实发布一定获得同样 CTR。
- 当前一键轻改是本地模拟版本，正式版会接入真实图片生成/编辑模型。
- 当前 SQLite 适合小规模测试，正式运营应迁移到云数据库。
